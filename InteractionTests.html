Expression Table Interaction Tests

Compare three ways of navigating to an expression and pressing Enter to copy it.

Testing instructions

  1. Use each table with the Virtual Cursor on first.
  2. Navigate to an expression using the method stated before its table.
  3. Press Enter and listen for the copy confirmation.
  4. Paste into Word or another application and confirm that only the expression was copied.
  5. Notice where focus remains and whether Forms Mode turns on.

The main Expression Library has not been changed. These tests use the same five expressions so only the interaction method changes.

Test 1: The expression is a button

Navigate as a normal table. In the Expression column, the expression itself is a button. Press Enter or Space to copy it. No separate Action column is used.

Optional menu test: while focused on an expression, press Shift+F10 or the Applications key for more actions.

Test 2: The table row receives focus

Press Tab to move to each complete row. Press Enter while the row has focus to copy its expression. Also try reaching a row with normal JAWS table navigation and pressing Enter.

Test 3: Interactive grid

Press Tab once to enter the grid. Use Up Arrow and Down Arrow to move among expression rows. Press Enter to copy the focused expression. Press Tab again to leave the grid.

Questions to answer

  1. Which test required the fewest keystrokes?
  2. Which test gave the clearest table and expression announcements?
  3. Did any test unexpectedly turn Forms Mode on or off?
  4. After copying, did focus remain on the same expression?
  5. Did Shift+F10 open the optional menu in Test 1?
