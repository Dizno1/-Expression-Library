Open Door Clipboard Tests

Compare three ways of copying Dino smiling as a small inline image.

How to test

  1. Activate one copy button.
  2. Move to Word or a chat application and paste on a blank line.
  3. Check whether an image appears, whether it stays near text size, and what the screen reader announces.
  4. Return here and repeat with the next test.

These tests require the HTTPS version of the Expression Library. Focus remains on the activated button after copying.

Test 1 - Small PNG

Copies only a 32-by-32-pixel PNG image. This tests size without alternative text or a text fallback.

Test 2 - Accessible HTML

Copies a 32-by-32-pixel inline HTML image with alternative text. A plain-text fallback reads: [Dino smiling].

Test 3 - Combined formats

Offers the receiving application a PNG image, accessible HTML, and plain text together.

Questions for each test

  1. Did anything paste?
  2. Was it an image, the words [Dino smiling], or both?
  3. Was the image close to inline text size?
  4. Did the screen reader announce that something was inserted?
  5. If an image was inserted, did its alternative text survive?
