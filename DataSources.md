# Data Sources

## Unicode Emoji 17.0

The complete fully qualified emoji repertoire is generated from:

`https://www.unicode.org/Public/emoji/latest/emoji-test.txt`

The source file is preserved at `data/unicode-emoji-test.txt`.

## Unicode CLDR 48

English short names and search annotations are generated from:

- `data/common/annotations/en.xml`
- `data/common/annotationsDerived/en.xml`

These files came from the Unicode CLDR 48 core distribution.

## Terms

Unicode data files are used under the Unicode Terms of Use:

`https://www.unicode.org/terms_of_use.html`

Vendor emoji artwork is not included. Emoji appearance is supplied by the user's operating system, browser, and installed fonts.

## Curated information

Open Door Design maintains the additional meanings, compatibility explanations, themes, and plain-language search terms in the project files.

## Open Door Expressions

Open Door Expressions are original image expressions created for this library. They are separate from the Unicode emoji repertoire and copy as images rather than text characters.
