How to use the Expression Library

Type in the Find an expression edit combo. Use Down Arrow and Up Arrow to review suggestions. Press Enter on a suggestion to copy it.

To browse, open a theme table and move through its expression buttons. Press Enter or Space to copy an expression. Frequently Used updates whenever an expression is copied.

Unicode expressions copy as text. Open Door image expressions copy as images where image clipboard access is supported. Alternative text may not remain attached after pasting an image into another application.

Preferences

Off announces the expression name and button role. On also announces meaning, type, and compatibility.

Find an expression

Type to receive suggestions. Use the Arrow keys to choose one and press Enter to copy it. Press Enter without choosing a suggestion to show all matches.
